This project develops a daily meal recommendation system for type 2 diabetic patients using Particle Swarm Optimization (PSO) and Content-Based Filtering (CBF). The system generates personalized meal recommendations based on users’ nutritional needs, including calorie, carbohydrate, protein, fat, and fiber requirements.

What I did?
- Collected and processed recipe and nutritional data from FatSecret through web scraping
- Calculated users’ daily nutritional requirements based on gender, age, body weight, height, and physical activity level
- Implemented Content-Based Filtering (CBF) and Particle Swarm Optimization (PSO) for meal recommendation generation
- Generated daily meal recommendations consisting of breakfast, morning snack, lunch, afternoon snack, and dinner
- Evaluated recommendation performance using MAE and RMSE metrics

Tools
Python
Flask

Output
A personalized meal recommendation system capable of generating daily meal plans for type 2 diabetic patients based on nutritional requirements.
